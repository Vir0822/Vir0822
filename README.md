I am a professional blockchain developer focused on building auditable smart contracts and reliable developer workflows. My work emphasizes security-first practices, extensive automated testing, clear integration patterns, and production-ready CI/CD pipelines.

<details>
<summary><strong>Professional approach</strong></summary>
